# UI Prototype: High-Fidelity Scheduling Experience

This prototype answers the question: **"How should the new Minimalist/Swiss design feel in practice?"**

## How to run
1. Start the frontend: `npm run dev` in the `frontend` directory.
2. Visit: `http://localhost:5173/?prototype=true`

## Variants Explored
- **Swiss Sidebar (Recommended):** The "approved" plan with a collapsible staging area and a high-fidelity weekly grid.
- **Ultra Minimal:** A focused view that hides the staging area behind a floating action menu to maximize calendar space.
- **Integrated:** (Conceptual) Merging the staging area directly into the calendar layout.

## Key Features Prototyped
- **Google Calendar Aesthetic:** 7-day weekly grid with separate all-day event row.
- **Proposal Preview:** "Ghost" events that appear with contextual badges (Weather, Routine alignment).
- **Staging Interaction:** Quick-add and detail list in a modern sidebar.
- **Current Time Indicator:** Visual orientation on the grid.

## Verdict
The **Swiss Sidebar** variant was enthusiastically approved by the user ("looks fucking amazing"). This is now the definitive design path for the high-fidelity UI implementation.
